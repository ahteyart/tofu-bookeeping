# tofu-bookeeping

AI-assisted bookkeeping automation for accounting firms, modelled on the workflow of Tofu (gotofu.com):
ingest source documents -> extract -> classify/code -> human review -> post to the accounting ledger.

> Status: **draft**. See [docs/modules.md](docs/modules.md) for the module design and
> [db/schema.sql](db/schema.sql) for the starter data model.
